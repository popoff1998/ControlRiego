Ardomo Webserver Maintenance Menu

The following pages are available:

  • HOME - HomePage
  • SYSINFO - System Information

    • OTA & File management:

  • FILES - Manage files on the server (browse, download or delete)
  • UPLOAD - Upload individual files
  • OTA update - Update Firmware or Filesystem

    • Testing:

  • /parmfile.htm - Manage configuration file
  • /parmfile_edit.htm - Edit configuration file
  • /parmfile_edit.htm?file=sampleParm.json - New configuration file

The following REST services are available:

  • /$sysinfo - Some system level information
  • /$list - Array of all files
  • /$list?dir=/backup - Array of all files in backup directory
