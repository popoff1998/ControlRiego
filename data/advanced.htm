Ardomo Webserver Maintenance Menu


  • HOME - HomePage
  • SYSINFO - System Information

OTA & File management:

    (ATENCION: Las siguientes opciones pueden alterar el funcionamiento del sistema)

  • FILES - Manage files on the server (browse, download or delete)
  • UPLOAD - Upload individual files
  • OTA update - Update Firmware or Filesystem

Testing:

  • OTA update (builtin) - Force built-in page
  • End webserver - Terminate Webserver

    • The following REST services return a JSON:

  • /api/sysinfo - Some system level information
  • /api/list - Array of all files
  • /api/list?dir=/backup - Array of all files in backup directory
  • /api/showZONElog?zona=1 - Show ZONE log
